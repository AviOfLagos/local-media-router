## Skill Usage Protocol
1. Receive requirement from marketing agent (via CMO or task board)
2. Read the source task and any attached files
3. Translate to developer-ready ticket format
4. Attach relevant files (corrected XML, JSON-LD, copy docs)
5. Tag severity and effort
6. Post to dev backlog or hand off to CEO for dev team routing
7. Track implementation status and verify when deployed
