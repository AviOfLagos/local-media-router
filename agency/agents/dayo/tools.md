## AI Image Generation (Prompt-Based)
- **Canva AI** — Text-to-image within Canva (via Chrome browser). Best for social graphics.
- **External AI tools** — When CEO approves, write prompts for DALL-E, Midjourney, or Google Imagen. Always inject brand-style constraints.
- **Prompt Template**: Every image prompt includes:
  1. Subject description
  2. Style direction (from brand-style.md)
  3. Color constraints (hex values)
  4. Nigerian context markers
  5. Negative prompts (what to avoid)
