How It Works

The agency operates through three core systems: agent activation, the heartbeat loop, and the content waterfall.

Agent Activation Flow

1. Heartbeat Check

The system loads each agent's memory file, reviews their task queue, and reports current status (IDLE, ACTIVE, or BUSY). This is the agency's pulse.

2. Task Assignment

Tasks are created via /assign or during sprints. Each task gets a priority (P0-P3), a deadline, and is routed to the appropriate agent based on their skills.

3. Agent Activation

When activated via /activate or /sprint, an agent loads its personality, memory, and context. It then executes tasks using its registered skills and tools.

4. Output & Handoff

Completed work is saved to the appropriate directory. If the task is part of the content waterfall, the output is handed to the next agent in the chain automatically.

5. Memory Update

After execution, the agent's memory is updated with what was done, decisions made, and any blockers encountered. This persists across sessions.

Content Waterfall

Every piece of content flows through this chain. Each agent adds their expertise before passing it forward.
